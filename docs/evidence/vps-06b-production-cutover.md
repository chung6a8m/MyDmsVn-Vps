## Production architecture and exact implementation

- **Typed production inventory:** [immutable review manifest](../contracts/vps-06b-typed-handler-manifest.json) records exactly **46 distinct request/response handler contracts implemented in 34 product handler classes** across Catalog, Identity, Inventory, Sales and Security. - **Packages and compilation:** `Mediator.Abstractions` + `Mediator.SourceGenerator` **3.0.2** centrally pinned, four SDK-10.0.404-generated files expected; `SourceGenerator` referenced **only by the outermost** `MyDmsVn.Server.AspNetCoreHost` executable (and the preexisting separate 06A canary), never by Application or Infrastructure libraries. Native production graph uses `Vps06bMediator=true`, `VPS06B_MEDIATOR`; `Server.Application` retains legacy conditional MediatR 12.5.0 on net48 and on its frozen standalone legacy fixture graph.
- **Compatibility:** 46 explicit native `ValueTask<ErrorOr<T>> IRequestHandler<TRequest,ErrorOr<T>>.Handle(...)` adapters delegate to **unchanged business `Task` implementations**, avoiding SQL transaction, unit-of-work, stock, COGS, permission or idempotency rewrites. `ApplicationRequest<T>` and the five HTTP controller files select native `Mediator` on net10 and legacy MediatR for net48. No Desktop or SQL script source changes.
- **Production DI:** Host calls `AddProductionGeneratedMediator` once at composition root, `ServiceLifetime.Scoped`, ordered `ExceptionHandlingBehavior → AuthorizationBehavior → ValidationBehavior → Handler`. Native message-aware delegates preserve the original cancellation, scoped identity, actor binding, permission/audit, error/sanitization and sequential validation code. Host tests replace handlers **after** generated DI to run the full frozen 57-route net48 JSON oracle without altering expectations.
- **Mandatory net10 build/publish syntax:** set **both** `-p:Vps04Server=true` **and** `-p:Vps06bMediator=true` at the command line for **all** Host and Host.Tests restore/build/test/publish commands. The latter must be an MSBuild global property so NuGet traverses all transitive project references as the same native graph. The three production and one Host.Tests `packages.vps06b.lock.json` files were regenerated by actual NuGet SDK 10.0.404, committed, and accepted only through **`--locked-mode`**. The historical net48 graph keeps its own packages and lockfiles unchanged.
